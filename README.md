# 🏆 World Cup 2018 Foosball Game

An immersive, browser-based 3D foosball game celebrating the 2018 World Cup. Experience the thrill of football in a unique and interactive way!

![Game Preview](./static/imgs/bg_mobile.jpg)

## 🎮 Features

- **3D Game Environment**
  - Realistic foosball table physics
  - Smooth player animations
  - Dynamic lighting and shadows
  - Immersive stadium atmosphere

- **Gameplay Elements**
  - Single-player and multiplayer modes
  - Multiple national teams to choose from
  - Real-time score tracking
  - Dynamic game events and celebrations
  - Tournament mode

- **Technical Features**
  - WebGL-based 3D rendering
  - Responsive design for all screen sizes
  - Modern glass-morphism UI
  - Custom sound effects and music
  - Smooth animations and transitions

## 🚀 Getting Started

### Prerequisites
- Modern web browser with WebGL support
- Python (for local development server)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/raihanulislam00/World-Cup-2018.git
cd World-Cup-2018
```

2. Start a local server:
```bash
python3 -m http.server 8000
```

3. Open in browser:
```
http://localhost:8000
```

## 🎯 How to Play

1. **Team Selection**
   - Choose your national team
   - View team statistics and rankings

2. **Game Controls**
   - Use arrow keys for player movement
   - Spacebar for shooting
   - 'P' for pause
   - 'M' for mute/unmute

3. **Game Modes**
   - Quick Match
   - Tournament
   - Practice Mode
   - Online Multiplayer
